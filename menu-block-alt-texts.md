# Navigation menu blocks — SEO alt text

SEO-optimised alt text for the two navigation-menu image blocks ("Onze showrooms" and "Klantenservice"), across all store views. Filenames stay English/global; only the alt text is localised.

## Files

| Block | Media path |
| --- | --- |
| Onze showrooms | `pub/media/wysiwyg/menu/tuinmaximaal-showroom-experience-centre.webp` |
| Klantenservice | `pub/media/wysiwyg/menu/tuinmaximaal-customer-service-advisor.webp` |

## Guidelines applied

- Descriptive, keyword-relevant, no keyword stuffing, kept under ~125 characters.
- `Tuinmaximaal` preserved intact; formal tone in French and German.
- No em-dash / en-dash used.
- Alt text reflects what is actually in the photo (showroom interior overview; a single advisor at a laptop).

## Notes

- `showroom` is kept as-is in Dutch and French (common loanword and brand-consistent with the physical showroom signage). German uses `Showroom`; if you prefer the stronger German search term, swap to `Ausstellungsraum`.
- The customer-service photo shows one female advisor, so the copy uses the singular. If future creative uses a different or mixed subject, revise accordingly.
